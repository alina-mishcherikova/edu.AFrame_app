Core functionality

The main technical features that power the AR exhibition experience.

Surface detection & object placement

Detect real-world surfaces and place sculptures/paintings precisely using hit-test and reticle feedback.

Exhibit transformation controls

Rotate, and move objects with intuitive controller interactions for fast scene customization.

Information System

Inspect exhibits with info boxes and a clean UI layer that stays readable inside AR passthrough.

Versions

Each version introduces new interaction logic.

Between worlds V1

  • Users can place up to four sculptures.
  • Each sculpture includes an interactive info box.
  • Visit mode prevents further placement.

Between worlds V2

  • Interactive menu for selecting exhibits before placement.
  • Support for placing paintings on vertical surfaces.
  • Rotation controls added.

Between worlds V2.2

  • Real-world occlusion.
  • Digital objects can be partially hidden by physical elements.
